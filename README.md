# Automotora DyP · Modelo Borrador

Modelo borrador del sistema de control de taller, construido por **Arttmize SpA**.

Se abre en **https://pruebas-dyp.github.io** — no se indexa en buscadores, se comparte por link.

Funciona en computador, tablet y celular. Las claves de demostración están a la vista en la
propia pantalla de ingreso.

> Los datos son de demostración: ningún dato real de clientes de la automotora.
